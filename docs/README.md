# Git & GitHub Mastery

> **From Beginner to Expert — Complete notes, dual-level examples, cheat sheets, and real-world workflows.**
> All in one structured, student-friendly repository.

---

## 📖 Introduction

Welcome to **Git & GitHub Mastery**! This repository is a complete, self-paced curriculum that takes you from **absolute beginner** to **advanced Git expert**.

Git is the **most widely used version control system** in the world, and GitHub is the largest host of source code. Whether you are a student, a freelancer, or a professional developer, mastering Git & GitHub is a **non-negotiable skill**.

### What makes this course different?

- 🟢 **Beginner Examples** — Real-life analogies and simple commands for newcomers.
- 🔵 **Expert Examples** — Professional, team-based scenarios for experienced developers.
- ⚠️ **Warnings** — Common mistakes and how to avoid them.
- 💡 **Pro Tips** — Insider knowledge and best practices.
- 🗺️ **Visual diagrams** — Mermaid and ASCII art to build mental models.

---

## 🎯 Prerequisites

- A computer (Windows, macOS, or Linux) with internet access.
- Basic comfort with the **command line / terminal** (navigating folders, running commands).
- **No prior Git experience required** — we start from zero.
- Curiosity and a desire to practice! Git is learned by *doing*, not just reading.

---

## 🛠️ How to Use This Repository

1. **Start at Part 1** and work your way through the parts in order — each part builds on the previous one.
2. **Follow along in your terminal.** Type every command yourself; muscle memory matters.
3. **Choose your level per concept.** If you are new, read the 🟢 Beginner example first. If you are experienced, jump to the 🔵 Expert example.
4. **Use the Cheat Sheet** when you need a quick command reference.
5. **Follow the Command Sequence** when you want to see the full real-world workflow end to end.
6. Each part ends with a **"Next Steps"** section that links you forward.

## 🏁 What Will You Achieve?

By the end of this course, you will be able to:

- ✅ Track and version any project with Git.
- ✅ Use branches and merges confidently — and resolve conflicts like a pro.
- ✅ Push, pull, and clone repositories on GitHub.
- ✅ Collaborate on open-source projects via **Pull Requests** and **code reviews**.
- ✅ Rebase, stash, cherry-pick, and recover lost commits.
- ✅ Understand what Git *actually is* under the hood (objects, trees, commits).
